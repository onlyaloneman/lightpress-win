轻压 LightPress  v1.1.0
========================================
图片 / GIF / 视频 体积优化工具（Windows 免安装）

【怎么用】
1. 双击 轻压.exe
2. 把文件拖进窗口，或点「+ 添加文件」（可一次选多个，也能添加整个文件夹）
3. 填「目标体积」，比如 7  —— 每个文件都会压到 7MB 以内
4. 点「开始压缩」，处理完点「打开输出目录」

默认输出到每个文件旁边的「_压缩」文件夹，不会动你的原文件。


【参数说明】
· 目标体积  按 1MB = 1,000,000 字节计算，比 1,048,576 更严格，
            这样微信 / 邮箱 / 各种上传限制都不会卡线。
            留空或填 0 = 质量优先模式（不限制体积，只做合理压缩）。
· 最长边    0 = 保持原始尺寸。填 1920 则长边超过 1920 的会自动等比缩小。
· 图片格式  自动 = 保持原格式（带透明通道的 PNG 不会被转成 JPEG）；
            也可以强制转 JPEG / WebP / PNG。WebP 通常比 JPEG 再小 25%~35%。
· 输出到    留空 = 每个文件旁新建「_压缩」文件夹；也可以指定一个固定目录。
· 增强引擎  pngquant / gifsicle，见下节。


【增强引擎（v1.1 新增）】
程序目录里放了两个小工具，勾选后自动启用，取消勾选就走内置算法：

· pngquant（压 PNG）
  对 PNG 做高质量调色板量化。同样体积下保留的颜色比内置算法多，
  观感更接近原图；同样观感下体积通常再小 15%~30%。
  质量模式（不填目标体积）时用 q≤95，基本看不出差别。

· gifsicle（压 GIF）
  用「轻微有损」换取体积，再配合帧间优化。
  实测同一目标体积下，分辨率能比不启用时提高一倍以上
  （例：7.6MB 的 GIF 压到 2MB，内置算法只能到 246×376，
   启用后能到 390×600，像素数 2.5 倍）。代价是处理慢一些。

  实测 lossy=40 档肉眼几乎无差别；体积仍超标时会自动升到 60/80/100。


【三种文件分别怎么压的】
· 图片：先按目标体积二分搜索编码质量；如果最低质量仍然超标，
        再自动等比缩小尺寸，直到压进目标以内。
        PNG 走 pngquant 时改为二分「质量上限」，能更精确地贴住目标。
· GIF ：用 ffmpeg 为这段动画单独生成 256 色调色板（palettegen），
        再配合 sierra2_4a 抖动和帧间差分编码。
        缩放比例不是靠面积线性外推（缩放后的重采样会让每像素体积翻倍），
        而是先用小尺寸探针标定「每像素字节数」和 gifsicle 折扣率，
        再一步算出目标尺寸，最后用实测值微调，通常 3 次内收敛。
· 视频：H.264 两遍编码。先按「目标体积 ÷ 时长」反算码率，
        编完实测如果还超标，自动收紧码率重编（最多 3 轮）；
        码率过低时会自动把分辨率降到 720p / 480p，避免糊成一片。


【常见问题】
Q: 提示「未找到 ffmpeg」？
A: 把 ffmpeg.exe 放到 轻压.exe 同一个文件夹里即可（本压缩包已附带）。
   图片压缩不依赖 ffmpeg，只有 GIF 和视频需要。

Q: 增强引擎显示「未安装」？
A: 把 pngquant.exe / gifsicle.exe 放到 轻压.exe 同目录即可。
   没有它们也能正常用，只是走内置算法，PNG/GIF 的体积和画质略差一点。

Q: 压完反而变大了？
A: 程序会自动检测，如果原文件已经更优，会保留原图并在状态里注明。

Q: GIF 压不到目标体积？
A: 会明确报错并给出「最小只能到多少」，不会给你一个超标文件。
   把目标调大一些，或取消勾选「保持原始帧率」。

Q: 处理很慢？
A: 视频两遍编码本身就慢；GIF 勾选 gifsicle 后需要多轮试算。
   一个 7.6MB / 2.5 秒的 GIF 大约 12~16 秒（不勾 gifsicle 约 3 秒）。

Q: 想批量脚本调用？
A: 支持命令行：
   轻压.exe --cli 视频.mp4 -t 7 -s 1920 -o D:\out
   -t 目标体积(MB)  -s 最长边(0=原尺寸)  -o 输出目录
   -f 图片格式(auto/jpeg/webp/png)
   --no-pngquant / --no-gifsicle 关闭对应引擎


【卸载】
绿色软件，直接删掉整个文件夹即可。
配置文件在 C:\Users\你的用户名\.lightpress\config.json（可留可删）。

核心引擎：Pillow + FFmpeg (libx264) + pngquant + gifsicle
